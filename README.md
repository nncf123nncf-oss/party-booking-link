# 団体予約の確認リンク（party-booking-link）

忘年会などの団体予約で、お店と幹事さんのあいだの「人数・コース・アレルギー」のやりとりを、リンクの往復にする1ページの道具です。

1. お店が、幹事さんの呼び名・予約日・開始時刻・用意できるコース（1〜4つ・1人あたりの料金）・飲み放題の有無・人数を決めてほしい日を入れて、確認リンクを作って幹事さんに送ります
2. 幹事さんは、人数（大人・子ども）・コースごとの人数・飲み放題をつける人数・アレルギーや苦手な食材（お名前は書かず、何が何人か）・お支払い・領収書を選び、返すリンクをお店に送り返します。コースの人数の合計が人数と合わないときは、リンクを作りません
3. お店は返ってきたリンクを開くと内容が表で見られ、「一覧に取り込む」で端末に予約の一覧（100件まで・予約日の近い順）を残せます。人数が変わって同じ確認リンクから送り直されたときは、前回と今回を並べて、変わった項目に印（▲▼）をつけてから上書きするか確かめます

- 一覧は、幹事さんが選んだ内容の控えです。予約の受付や確定はしません
- アレルギー・苦手の欄は、事前に伝えてもらうためのメモです。対応できるかどうかは判断しません
- 合計の金額は、コースの料金×人数＋飲み放題の料金×人数の目安です。お会計とは違うことがあります
- お店の一覧は、お使いの端末のブラウザ（localStorage）にだけ保存します。ブラウザのデータを消すと一覧も消えます。返ってきたリンクから取り込み直せます。読み取れなかった保存データは、日時つきの別のキーに新しい3回ぶんまで残します
- 聞く内容・返す内容はURLの `#` 以降に入ります（`#q1=`・`#a1=`）。確認リンクごとに番号が付き、同じリンクへの送り直しだけを「同じ件」として比べます
- サーバー・アカウントは使いません。閲覧数の計測に Cloudflare Web Analytics を使っています
- リンク・メールアドレス・7桁以上の数字・請求や振込に見える言葉・金額は、文字の欄に入れられないようにしています（料金は数字の欄だけで受けます。すべての言い方は防げません）
- 確認は確認ダイアログではなく、画面の中のボタンで行います（アプリ内ブラウザで確認ダイアログが出ない場合に備えて）
